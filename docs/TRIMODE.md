# 三模与 8 kHz

芯片锁定见 [CHIP_LOCK.md](CHIP_LOCK.md)。

| 问题 | 答案 |
|---|---|
| 主控？ | **新唐 M487**，CON1 **8 kHz** |
| 主板蓝牙？ | **杰里 AC632N**（BLE + 经典蓝牙 EDR）。不用 nRF52840 |
| 2.4G 接收器？ | **CH32V305** + **Si24R1**，开发板 CH32V307V-EVT，**4 kHz** |
| 杰里私有 2.4G？ | 不用。对不上 Si24R1，杰里 USB 也只有 1 kHz |
| 经典蓝牙没芯片？ | AC632N 就有。ESP32-S3/C3、nRF52 没有 |
| 连 Xbox / PS / Switch？ | 本方案不做主机仿冒。电脑/手机蓝牙可以 |
| Pico？ | 旧板可以，新板不要 RP2040 |
